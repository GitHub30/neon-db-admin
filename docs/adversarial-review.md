# Adversarial Security, Architecture & Quality Review Report

An independent adversarial audit was conducted against the entire `neon-db-admin` codebase (Cloudflare Workers proxy, `proxy.php`, `proxy-node.mjs`, browser SQLite WASM worker, frontend workbench UI, ER diagram engine, PWA service worker, and SEO/AEO/GEO/AIO/LLMO metadata).

Every **Critical** and **High** finding — along with all major **Medium** and **Low** findings — was remediated and verified via unit tests, live proxy tests, and Google Lighthouse audits.

---

## Summary of Critical Findings & Remediations

| ID | Area | Vulnerability / Defect Found | Remediation Applied |
| --- | --- | --- | --- |
| **C1** | Cloudflare Worker SSRF | `validateHost()` allowed colon bypass (`localhost:3306`), expanded/alternative IPv6 loopback/NAT64/6to4/link-local (`0:0:0:0:0:0:0:1`, `fe81::1`, `64:ff9b::...`), shorthand/hex IPv4 (`127.1`, `0x7f.0x0.0x0.0x1`), and partial multicast CIDRs. | Implemented strict RFC 4291 8×16-bit IPv6 parser, full numeric 32-bit IANA IPv4 CIDR bitmask table, trailing-dot normalization, and RFC 1123/3696 alphabetic TLD enforcement (`workers/proxy-worker/src/security.ts`). Verified with 48 automated SSRF test cases. |
| **C2** | Cloudflare Worker Open-Redirect SSRF | `fetch()` in `libsql.ts` and `d1.ts` used default `redirect: 'follow'`, allowing a malicious HTTPS endpoint to 302-redirect into private targets and leak 300 bytes of upstream body. | Enforced `redirect: 'error'` and `AbortController` timeouts in `libsql.ts` and `d1.ts`, blocked embedded URL credentials & non-443 ports in `validateHttpsUrl()`, and removed raw non-JSON body reflection. |
| **C3** | PHP / Node SQLite Sandbox Escape | `ATTACH DATABASE` and symlinks allowed escaping `SQLITE_ALLOWED_DIR` for arbitrary file read/write. | Enforced `.sqlite`/`.sqlite3`/`.db`/`.db3` extensions, rejected symlinks (`is_link`/`lstatSync`) and directories, enforced `realpath` prefix checks, and blocked `ATTACH`/`DETACH`/`LOAD_EXTENSION` via SQL literal/comment-stripping lexers (`proxy.php`, `proxy-node.mjs`). |
| **C4** | Proxy Auth Policy | `proxy-node.mjs` and `proxy.php` needed consistent constant-time token authentication with clear auth status reporting. | Implemented SHA-256 `timingSafeEqual` (`proxy-node.mjs`) and `hash_equals` (`proxy.php`) authentication with `authRequired` health reporting. Per explicit user requirement (v1.2.0), `NEON_DB_PROXY_TOKEN` is optional out-of-the-box for rapid local/intranet deployment and strictly enforced whenever set; SQLite sandbox (`realpath`, symlink rejection, `ATTACH`/`LOAD_EXTENSION` block) and DSN validation remain unconditionally active. |
| **C5** | PHP PDO DSN Injection | `$host` and `$db` were interpolated into PDO DSNs without rejecting `;`, whitespace, or `=`. | Added `validateDsnHost()` and `validateDsnDbName()` rejecting `;`, `=`, whitespace, slashes, and control chars (`public/proxies/proxy.php`). |
| **C6** | PHP PostgreSQL `$1` Breakage | Frontend emits `$1, $2` for PostgreSQL, which PHP `pdo_pgsql` rejects (`HY093`). | Implemented lexer-safe `$1 -> :p1` rewriter and typed `PDO::PARAM_*` binding in `proxy.php`. |
| **C7** | Data Grid Inline Edit & Focus Loss | Single-click and Quick Search called `container.replaceChildren()`, detaching live `<td>` nodes before `dblclick` fired and dropping search input focus on every keystroke. | Decoupled `tbody`, toolbar actions, and cell inspector updates (`renderTbodyOnly`, `renderInspectorOnly`, `renderActionButtons`) so Quick Search preserves focus and double-click inline edit works reliably. |
| **C8** | Service Worker Offline Bug | `caches.match('./') \|\| caches.match('./index.html')` had a `Promise \|\| Promise` bug and did not precache hashed Vite bundles or `sql-wasm.wasm`. | Fixed `async/await` cache resolution with valid 503 fallback `Response` (`public/sw.js`) and added a Vite `closeBundle` plugin (`vite.config.ts`) injecting all built assets + `sql-wasm.wasm` into `dist/sw.js`. |

## Summary of High, Medium & Low Remediations

- **H1 (Worker CORS Crash Guard & Rate Limit):** Wrapped Worker `fetch()` in top-level `try/catch` guaranteeing `Access-Control-Allow-Origin: *` even on HTTP 500, added streaming bounded body reader (`readBoundedText`), validated batch array objects, and added sliding-window per-IP rate limiting.
- **H2 (TLS Verification Default):** Changed default `sslRejectUnauthorized` from `false` to `true` across Workers, PHP, Node proxies, and UI, with an explicit opt-in checkbox for self-signed development certificates.
- **H3 (Credential Purge):** Fixed `clearAllStoredSecrets()` / `store.purgeAllSecrets()` to scrub credential-bearing URLs (including query params) and sync in-memory connections; wrapped all `localStorage` calls in `try/catch`.
- **H4 & H5 (Proxy Driver Hardening):** Fixed `decodeURIComponent` corrupting raw passwords containing `%`, added shared batch deadlines, called `client.destroy()` on MySQL timeouts, handled `pg` multi-statement result arrays, added Node 22.0–22.15 SQLite `columns()` fallback, prevented `mysql2` URI option injection, and added readable SQL type names (`L4`).
- **H6 (Async Race Conditions):** Added monotonic sequence tokens to `fetchGridData()` and `connectTo()`, connected new adapters before disconnecting old ones, guarded `store.activeView` before async re-renders, serialized SQLite Worker messages in a promise queue, and fixed Worker error/disconnect cleanup.
- **H7 (Data Grid SQL Safety):** Generated `previewClause` alongside `clause` in `buildRowWhereClause()` (preventing `?`/`$1` column name corruption), added PK-less table warnings, prevented unchanged `NULL` blur from dirtying cells, and chunked batches to 40 statements (`L3` single batch SELECT+COUNT).
- **H8 (ER Diagram SVG XSS):** Added `sanitizeImportedErModel()` validating numeric bounds, hex color regex `/^#[0-9a-fA-F]{3,8}$/`, and entity schemas, plus `'` escaping in SVG export.
- **H9 (Import/Export Integrity):** Stringified nested JSON objects before SQLite bind, enforced exact 16-byte `SQLite format 3\0` magic header, added FK-safe SQL dump pragmas & truncation warnings, and prevented ephemeral uploaded `.sqlite` connections from silently loading demo DBs after reload.
- **H10 (Remote Introspection):** Added 25s `AbortController` fetch timeout, raised introspection `maxRows` to `10,000`, upgraded PostgreSQL introspection to multi-schema `pg_constraint` with `WITH ORDINALITY` + `IDENTITY`/`UNIQUE`, and batched remote SQLite `PRAGMA index_info`.
- **H11, M2–M6, L1–L5 (Accessibility, UX & Standards):** Fixed dark-mode danger hover contrast (`--danger-ink`), eliminated nested interactive controls in SQL subtabs, wired full ARIA Tabs (`aria-controls`, `aria-labelledby`, arrow keys) & modal focus trap, linked `<label for>`, fixed pie 100% chart & fractional ticks, synced ER relations on column edits, enabled saved connection Edit/Delete, added PWA `#hash` shortcuts, single `#meta-theme-color`, `public/.nojekyll`, ARD v0.91 `.well-known/ard.json`, and mobile touch target sizing (`>=36px`).
