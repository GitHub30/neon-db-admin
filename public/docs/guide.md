# Neon DB Admin User Guide

## Getting Started
1. Open [Neon DB Admin](https://github30.github.io/neon-db-admin/) in any modern browser.
2. Click **サンプルDBを今すぐ起動** to test with an E-Commerce SQLite database running locally in WebAssembly, or drag-and-drop any `.sqlite` / `.db` file onto the window.
3. Click **接続管理 (Connections)** to connect to MySQL, MariaDB, PostgreSQL, Cloudflare D1, or LibSQL via the built-in Cloudflare Workers proxy or your own `proxy.php` / `proxy-node.mjs`.

## Keyboard Shortcuts
- `Ctrl+K` / `Cmd+K`: Open fuzzy Command Palette
- `Ctrl+Enter` / `Cmd+Enter`: Execute SQL query (or selected text)
- `Ctrl+Space`: Trigger SQL autocomplete suggestions
- `Double-click cell`: Start inline cell edit in Data Grid
- `Escape`: Close modal or cancel inline edit
