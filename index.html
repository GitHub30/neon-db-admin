Neon DB Admin — マルチデータベース対応ブラウザ管理ツール & ER図デザイナー

Neon DB Admin は、phpMyAdmin・Adminer・DB Browser for SQLite・MySQL Workbench・pgAdmin・DBeaver・DbGate の実用的なワークフローを1つの軽量PWAへ統合したユニバーサルデータベースクライアントです。ブラウザのみでローカル SQLite ファイルを安全に編集でき、CORS (Access-Control-Allow-Origin: *) 対応の Cloudflare Workers プロキシまたは proxy.php を通じて本番・検証環境のリモートDBへ接続できます。

データ閲覧・インライン編集

ページネーション・SQLソート・複数条件WHEREフィルタビルダー・ダブルクリックでのセル直接編集・SQLプレビュー付きバッチコミット・外部キーリンクジャンプ・セルJSON整形インスペクタを備えています。

高機能 SQL IDE & チャート

マルチタブ対応エディタ、シンタックスハイライト、テーブル/カラム自動補完 (Ctrl+Space)、EXPLAIN 実行計画、SQL整形、履歴・スニペット管理、実行結果からの棒/折れ線/円グラフ即時生成に対応します。

MySQL Workbench 風 ER図設計

既存DBからの自動リバースエンジニアリング、Crow's Foot記法 (1:1 / 1:N / N:M)、ドラッグ配置・階層自動レイアウト、各SQL方言へのフォワードDDL生成、SVG・PNG・Mermaid・DBML書き出しに対応します。

診断・差分・インポート/エクスポート

主キー欠如や未インデックス外部キーの1クリック最適化、ERモデルとのスキーマ差分マイグレーション生成、外部キー整合モックデータ生成、SQLダンプ・CSV/TSV/JSON自動型推論インポートを内蔵しています。

よくある質問 (FAQ)

SQLiteファイルを開いたとき、データは外部サーバーに送信されますか？

いいえ。ローカルの .sqlite / .db ファイルはブラウザ内の WebAssembly (sql.js) と専用 Web Worker 上でのみ処理されるため、ファイルの内容が外部サーバーへアップロードされることはありません。オフライン環境でもPWAとして動作します。

静的サイト（GitHub Pages）からMySQL・MariaDB・PostgreSQL・Cloudflare D1に接続できるのはなぜですか？

ブラウザは直接TCPソケットを開けないため、Access-Control-Allow-Origin: * を返す Cloudflare Workers プロキシ（cloudflare:sockets TCP / D1 REST API対応）、またはセルフホスト可能なシングルファイル proxy.php / proxy-node.mjs を中継して安全にクエリを実行します。

MySQL WorkbenchのようなER図の作成・リバースエンジニアリングに対応していますか？

はい。接続中のデータベースからテーブル・主キー・外部キーを自動解析してCrow's Foot記法のER図をリバース生成できます。さらにキャンバス上でテーブルやリレーションを視覚的に設計し、SQLite・MySQL・MariaDB・PostgreSQL・D1向けのCREATE TABLE DDLをフォワード生成、SVG・PNG・Mermaid・DBML形式で書き出せます。

パスワードやAPIトークンはどのように保護されますか？

初期設定ではパスワードやAPIトークンはlocalStorageに永続保存されず、タブを閉じると消去されるsessionStorageのみに保持されます。またCloudflare WorkersプロキシはプライベートIP・メタデータIPへのSSRF防御と任意のトークン認証を備えています。
